# Generate employee data

## Employee data format in table
| Property name | Property type | Description |
|----------------|---------------|-------------|
| Employee ID | Integer | Unique identifier for each employee (UUID) |
| First Name | String | The first name of the employee (max length: 100 characters) |
| Last Name | String | The last name of the employee (max length: 100 characters) |
| Email | String | The email address of the employee (max length: 100 characters) |
| Credit Card Number | String | The credit card number of the employee (max length: 16 characters) |
